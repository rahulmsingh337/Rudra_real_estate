# Project photos

1. Put originals in a folder, then run `python3 scripts/optimize-photos.py path/to/originals`.
2. List each file in `js/config.js` under `photos` (src, title, place, alt).
3. The "Projects" section appears on the site when there are 3 or more.

Use only photos Rudra Real Estate owns or has permission to publish. Keep each file under about 200 KB.
